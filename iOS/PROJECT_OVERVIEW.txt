    ↓

───────────────────

✨ WHAT'S DIFFERENT FROM ANDROID
═══════════════════════════════════════════════════════════════════════════════

FIXED: Background Termination Bug
──────────────────────────────────
Android Version ❌
  override fun onDestroy() {
      syncToFirebase()  // Might not complete!
  }

iOS Version ✅
  private func setupObservers() {
      NotificationCenter.default.publisher(for: UIApplication.willTerminateNotification)
          .sink { [weak self] _ in
              self?.persistBalance()  // Runs BEFORE app closes
          }
  }

Result: Data is GUARANTEED to save before app terminates!
